## 已通过

- 编译所有已配置目标，包括主库、新旧 RGB-D、单目、双目、单目惯性、双目惯性示例、验证程序和 g2o。完整日志 `build.log`、`build-final.log`；额外 transition 测试目标编译日志 `build-transition.log`；日志重写和独立 C++ 配置校验修正后的全目标构建日志为 `build-debug-log.log`、`build-config-validation.log`。
- 真实图像检测到 11 个实例，类别包含 0、39、56、62、64、66；人工查看叠加图，人员/椅子/显示器等语义区域与输入图像位置一致。
- RGB 与 BGR 两种表示产生完全相同的合并 mask；原 RGB 缓冲逐像素未变。所有实例 mask 与图像同尺寸，只在对应检测框内非零；all 并集和 selected `[0,56]`（person、chair，真实图中两类都存在）的并集逐像素符合策略。
- 所有开启屏蔽的真实序列帧和尺寸测试的最终关键点中心均未落入屏蔽区域，`violations=0`。独立的半图遮挡及全遮挡测试也通过。
- 640×480、480×640、321×239、960×320、160×120 的真实内容缩放测试；额外 180×640 窄竖图特征提取通过。纵向尺寸用真实图像内容生成测试夹具，没有额外原生竖拍数据集。
- System 内部缩放为 320×240：5 帧成功跟踪、保存 5 行轨迹，mask PNG 尺寸严格为 320×240，关键点违规 0。
- 合法空检测：置信度设为 1.0，5 帧检测数和屏蔽比例均为 0，正常跟踪并保存 5 行轨迹。
- 全屏蔽：使用半径 640 的正方形膨胀核，5 帧屏蔽比例均为 100%，关键点均为 0，保持 NOT_INITIALIZED；保存空轨迹并明确记录未初始化，没有取消 mask、越界或崩溃。
- 已初始化后的全屏蔽：用无检测随机纹理及恒定深度夹具初始化为 OK（964 点），再送入全屏蔽的真实 TUM RGB 帧，正常进入 LOST，0 特征。`transition.log` 显示 `TRACK_REF_KF: Less than 15 matches`、`Fail to track local map`、`tracking_state=4 (mask retained)`。这项检查验证失败控制流，不用于评价轨迹精度。
- 关闭功能、原始四位置参数运行：原 TUM3 配置副本仅增加 `Run.Viewer: 0`，无 SemanticMask 字段；30 帧全部 OK，保存 30 行轨迹。输出在 `legacy/`。该原配置仍保留旧 Camera.RGB=1，所以性能/轨迹对比表使用修正 BGR 的 off 组。
- 不传 mask 的原调用与全允许 mask 的关键点坐标和描述子完全一致。
- 错误模型文件、selected 缺少类别列表明确抛出异常，无静默回退；YAML 和直接构造 C++ 配置两个入口均已测试。最终模块回归日志为 `final-module.log`。
- 同一调试目录连续运行两次，CSV 仅保留本次的一个表头和 5 条记录，无重复表头，所有违规计数为 0；见 `rerun-first.log`、`rerun-second.log`。
- 无 ORT 宏时 `SemanticMasker.cc` 通过 C++11 独立语法检查，见 `without-ort-syntax.log`。

## 未验证与限制

- 未计算 ATE/RPE，未验证长序列稳定性、地图质量、轨迹精度变化或泛化效果。三组短序列状态 OK 不代表精度提升。
- 当前实测启用屏蔽约 333–336 ms/帧，未达到 30 Hz；未声称实时。第一版保留同步逐帧处理，不跳帧。
- 没有安装 RealSense SDK，CMake 未生成相应设备目标，未编译/运行这些可选目标；单目、双目、惯性模式完成编译兼容性验证，未用对应传感器数据运行；独立 ROS 工程未配置/编译。
- 未实际构建并链接整套 `WITH_ONNX_RUNTIME=OFF` 变体，只做该分支的 C++11 源码语法检查；运行开关关闭和旧调用方式已实际运行验证。
- 未与 Python Ultralytics 输出逐像素对比；本机没有 Python ultralytics/onnxruntime/cv2。当前验证包括张量结构、数学解析、并集、裁剪、坐标、可视检查和最终关键点不变量。概率插值顺序在实现文档中明确，可能与其他实现的裁剪/插值顺序存在边界差异。
- 未对篡改后的输出张量形状/类型做故障注入；初始化和逐帧输出检查均已实现，真实模型结构检查已运行。
- 灰度/四通道分支已实现，但本次真实数据为三通道，未执行这两个分支的模型回归。
- `all` 会屏蔽静态语义对象，例如椅子、显示器；检测类别不代表实际运动。mask 之外的模型漏检区域仍可能保留特征，膨胀默认关闭。
- 调试图形标记本身有半径，圆圈可能与红色区域相交；不变量约束的是关键点中心的 floor 像素。最终特征判定使用提取图像坐标，不使用去畸变后的坐标。
